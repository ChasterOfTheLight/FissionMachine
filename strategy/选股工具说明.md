## 📚 功能介绍

### ✅ 核心功能

1. **自动获取A股数据**：使用 AkShare 实时获取市场数据
2. **智能过滤**：
   - 排除 ST、退市股
   - 排除科创板（688）、北交所（8/4开头）
   - 排除停牌股票（成交量为0）
   - 排除价格异常股票
3. **双维度评分**：
   - 技术面评分（60%权重）：涨跌幅、成交量、换手率、振幅、量比
   - 基本面评分（40%权重）：市盈率、市净率、流通市值、60日涨跌幅
4. **自动保存结果**：CSV格式，方便后续分析

---

## 🎯 评分标准

### 技术面评分（100分）

| 指标 | 权重 | 最佳范围 |
|------|------|----------|
| 涨跌幅 | 20分 | 3%-7% |
| 成交量 | 20分 | >10万手 |
| 换手率 | 20分 | 2%-10% |
| 振幅 | 20分 | 2%-8% |
| 量比 | 20分 | >1.5 |

### 基本面评分（100分）

| 指标 | 权重 | 最佳范围 |
|------|------|----------|
| 市盈率 | 30分 | 0-20 |
| 市净率 | 30分 | 0-2 |
| 流通市值 | 20分 | 50-500亿 |
| 60日涨跌幅 | 20分 | >20% |

### 综合评分

```
综合评分 = 技术面评分 × 60% + 基本面评分 × 40%
```

## 📖 使用示例

### 示例1：快速选股（推荐）

```python
from simple_stock_picker import quick_pick

# 选出前20只股票
result = quick_pick(top_n=20)
```

### 示例2：自定义数量

```python
from simple_stock_picker import SimpleStockPicker

picker = SimpleStockPicker()
result = picker.run(top_n=10)  # 只选前10只
```

### 示例3：自定义过滤条件

```python
from simple_stock_picker import SimpleStockPicker

picker = SimpleStockPicker()

# 获取并过滤股票
stocks = picker.get_all_stocks()
stocks = picker.filter_basic(stocks)

# 自定义：只要涨幅在0-5%之间的
stocks = stocks[(stocks['涨跌幅'] > 0) & (stocks['涨跌幅'] < 5)]

# 评分排名
result = picker.rank_stocks(stocks, top_n=15)

# 格式化输出
output = picker.format_output(result)
print(output)

# 保存结果
picker.save_result(result, filename="自定义选股.csv")
```

### 示例4：只看强势股（涨幅>5%）

```python
picker = SimpleStockPicker()
stocks = picker.get_all_stocks()
stocks = picker.filter_basic(stocks)

# 筛选强势股
stocks = stocks[stocks['涨跌幅'] > 5]

result = picker.rank_stocks(stocks, top_n=10)
picker.save_result(result, filename="强势股榜单.csv")
```

### 示例5：低估值选股（市盈率<20，市净率<2）

```python
picker = SimpleStockPicker()
stocks = picker.get_all_stocks()
stocks = picker.filter_basic(stocks)

# 筛选低估值
stocks = stocks[(stocks['市盈率-动态'] > 0) & 
                (stocks['市盈率-动态'] < 20) &
                (stocks['市净率'] > 0) &
                (stocks['市净率'] < 2)]

result = picker.rank_stocks(stocks, top_n=20)
picker.save_result(result, filename="低估值股票.csv")
```

## 🔧 进阶用法

### 定时自动选股

```python
import schedule
import time
from simple_stock_picker import quick_pick

def daily_pick():
    """每天选股"""
    print(f"\n开始每日选股 - {datetime.now()}")
    quick_pick(top_n=20)

# 每天早上9:30运行
schedule.every().day.at("09:30").do(daily_pick)

# 持续运行
while True:
    schedule.run_pending()
    time.sleep(60)
```

### 批量选股（多个策略）

```python
strategies = {
    "强势股": lambda df: df[df['涨跌幅'] > 5],
    "低估值": lambda df: df[(df['市盈率-动态'] < 20) & (df['市净率'] < 2)],
    "高成交": lambda df: df[df['成交量'] > 200000],
    "活跃股": lambda df: df[df['换手率'] > 5]
}

picker = SimpleStockPicker()
stocks = picker.get_all_stocks()
stocks = picker.filter_basic(stocks)

for name, strategy in strategies.items():
    filtered = strategy(stocks)
    result = picker.rank_stocks(filtered, top_n=10)
    picker.save_result(result, filename=f"{name}_选股结果.csv")
    print(f"\n{name} 策略完成！")
```
